## Hey, I'm Raunak

Software engineer. I mostly build developer tools: code editors, language tooling, desktop apps and AI agents. Lately I've been writing a lot of Rust.

I maintain [**Acode**](https://github.com/Acode-Foundation/Acode), a code editor for Android with 7.7k+ stars, and I'm its top contributor by commits. Most of what I build around it lives under [Acode-Foundation](https://github.com/Acode-Foundation).

### What I'm working on

- [**Acode AI Agent**](https://github.com/Acode-Foundation/acode-ai-agent): an AI coding agent that runs inside Acode
- [**canvas-view**](https://github.com/Acode-Foundation/canvas-view): a GPU-rendered (WebGL2 / WebGPU) editor view for CodeMirror 6, built to make scrolling and typing smooth on Android WebView
- [**Acode migration**](https://github.com/Acode-Foundation/Acode-migration): migrating Acode from Cordova to a Proteus-based setup
- [**Setu**](https://github.com/bajrangCoder/setu): a fast, minimal desktop API client written in Rust with GPUI
